# Netflix Clone - Responsive Frontend Project

A fully responsive, interactive replica of the Netflix landing page, content rows, and FAQ interface built from scratch using semantic HTML5, modern CSS3 layout engines, and vanilla JavaScript.

## 🚀 Live Demo
You can view the live deployed application here: [(https://aksharasachan.github.io/flix-stream-ui/)]

---

## ✨ Features

- **Cinematic Hero Overlay:** Implements a realistic dark-gradient layout overlay layered seamlessly on top of a dynamic high-resolution background asset.
- **Interactive Movie Rows:** Leverages CSS Flexbox and horizontal scrolling tricks (`overflow-x`) paired with subtle smooth scaling micro-interactions (`transform: scale()`) to mimic the official platform streaming tracks.
- **Vanilla JS Accordion:** A lightweight, logic-driven FAQ dropdown widget engineered using JavaScript to track class toggles and compute smooth, animated sliding panel visibility transformations.
- **Fluid Layout Responsiveness:** Completely optimized across distinct breakpoint layers using CSS Media Queries to rearrange content gracefully from expansive desktop environments down to mobile portrait views.

---

## 🛠️ Tech Stack & Methods

- **Structure:** `HTML5` using clean semantic syntax structure (`<header>`, `<nav>`, `<main>`, `<section>`).
- **Styles:** `CSS3` utilizing Flexbox distribution alignments, explicit positioning layers (`absolute`/`relative`), webkit-scrollbar modifications, and responsive `@media` break parameters.
- **Interactivity:** Modern `Vanilla JavaScript` (DOM Manipulation, conditional event listeners, and programmatic rendering tracking configurations).
